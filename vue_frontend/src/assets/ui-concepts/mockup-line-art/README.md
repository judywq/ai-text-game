# Line-art login concept

This folder is a standalone, responsive login-page concept. It deliberately does not import the Vue application, change a production route, or depend on image assets.

Open either page in a browser to review the design:

- `login.html` - account entry
- `game-setting.html` - genre, prompt, reading level, and recent-story setup
- `gameplay.html` - story reader, choices, and margin notes
- `game-loading.html` - story initialization and ready state
- `library.html` - game history and continuation entry point
- `profile.html` - reader preferences and account settings
- `home.html` - signed-in welcome and story prompt
- `quiz.html` - vocabulary review
- `signup.html`, `verify-email.html`, `forgot-password.html`, `reset-password.html`, `password-reset-sent.html`, `change-password.html` - account flows
- `terms.html`, `privacy.html`, `not-found.html` - support and legal pages

Both pages use CSS-only book framing, a subtle dotted background, and a small set of line details. They have desktop, tablet, and narrow-mobile layouts built into their respective stylesheets.
